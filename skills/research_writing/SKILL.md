# Research Writing

Use this skill when the user asks for help drafting, polishing, structuring, or preparing research papers, academic manuscripts, LaTeX projects, Overleaf templates, or related writing prompts.

## Resources

- Start with `README.md` for the curated overview.
- Use `OVERLEAF_LINKS.md` for common journal and conference template references.
- Use `HUMANIZER_LINKS.md` when the user asks about Humanizer or humanizing wording.
- Use `README_source_*.md` as offline upstream references when relevant.

## Guidance

When helping with research writing:

- Preserve the user's target field, journal, style guide, and terminology.
- Prefer concrete manuscript structure, checklist items, or editable text over broad advice.
- For LaTeX or Overleaf requests, point to the relevant template source and adapt commands to the user's environment.
- For prompt-generation requests, provide reusable prompts with clear inputs, expected outputs, and constraints.
