# Research Paper Writing Resources

This folder collects curated links and local copies (where possible) of README/guides
for research paper writing, LaTeX templates, Overleaf templates, and writing tools.

Primary curated links:
- arXiv / LaTeX templates: https://github.com/kourgeorge/arxiv-style
- Project template (code+paper): https://github.com/gboeing/project-template
- Academic research skills repository: https://github.com/Imbad0202/academic-research-skills
- ChatGPT prompts for academic writing: https://github.com/ahmetbersoz/chatgpt-prompts-for-academic-writing
- Overleaf templates: https://www.overleaf.com/latex/templates
- Pandoc (Markdown <-> LaTeX conversions): https://pandoc.org/
- Humanizer links: HUMANIZER_LINKS.md
- Jupyter live kernel links: JUPYTER_LIVE_KERNEL_LINKS.md

Note: This repository contains local copies of README files fetched from upstream when available.
If a README couldn't be downloaded automatically, please refer to the links above.
